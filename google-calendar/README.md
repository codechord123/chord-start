# 선생님 캘린더 (데스크탑 앱)

선생님이 만든 구글 캘린더 + TODO 위젯(`index.html`)을 Windows 바탕화면에 자연스럽게 붙어있는 위젯으로 실행합니다.  
파이썬(PyQt6 WebEngine)이 내부 브라우저로 `index.html`을 표시하므로 화면과 기능이 웹 버전과 100% 동일합니다.

---

## 설치 (한 번만)

이 폴더 전체를 Windows PC에 복사한 다음, 아래 중 **하나만** 더블클릭하세요.

| 파일 | 설명 |
|------|------|
| `install.bat` | 파이썬 버전 자동 감지 — 보통 이걸로 충분합니다 |
| `install_py312.bat` | Python **3.12** 버전이 확실할 때 |
| `install_py314.bat` | Python **3.14** 버전이 확실할 때 |

설치 스크립트가 하는 일:
1. PyQt6 + PyQt6-WebEngine 패키지 자동 설치 (첫 실행 시 약 150 MB 다운로드)
2. Windows 시작프로그램에 자동 등록
3. 캘린더 즉시 실행

이후 컴퓨터를 켤 때마다 캘린더가 자동으로 시작됩니다.

---

## 파일 설명

| 파일 | 용도 |
|------|------|
| `index.html` | 실제 캘린더 화면 (수정하면 앱에도 그대로 반영) |
| `desktop_app.py` | index.html을 바탕화면 위젯으로 띄우는 런처 |
| `install.bat` | 설치 (자동 버전 감지) |
| `install_py312.bat` | 설치 (Python 3.12 전용) |
| `install_py314.bat` | 설치 (Python 3.14 전용) |
| `start_silent.vbs` | 수동으로 켤 때 더블클릭 (검은 창 없음) |
| `uninstall.bat` | 시작프로그램 등록 제거 |

## 창 조작

| 동작 | 방법 |
|------|------|
| 위치 이동 | 상단 바를 드래그 |
| 📌 항상 위에 고정 | 상단 바 오른쪽 📌 클릭 |
| ↻ 새로고침 | 상단 바 오른쪽 ↻ 클릭 |
| 숨기기 / 다시 표시 | 상단 바 **—** 클릭 → 우하단 트레이 아이콘 📅 클릭 |
| 크기 조절 | 우하단 모서리 드래그 |
| 종료 | 상단 바 **✕** 또는 트레이 메뉴 → 종료 |

상단 바는 평소에는 투명하고, 마우스를 올리면 나타납니다.

## ⚠️ 구글 로그인 관련 (중요)

데스크탑 앱은 `http://localhost:8765` 주소로 페이지를 띄웁니다.  
구글 로그인이 작동하려면 **구글 클라우드 콘솔**에서 이 주소를 허용해야 합니다.

1. https://console.cloud.google.com/apis/credentials 접속
2. 사용 중인 OAuth 클라이언트 ID 클릭
3. **승인된 자바스크립트 원본** 에 아래 추가:
   ```
   http://localhost:8765
   http://localhost:8766
   http://localhost:8767
   ```
4. 저장 후 몇 분 기다렸다가 앱에서 로그인

> TODO 목록은 로그인 없이도 바로 사용 가능합니다 (이 PC에만 저장됨).

## 수동 실행 / 재시작

- `start_silent.vbs` 더블클릭 — 검은 콘솔 창 없이 조용히 실행
- 또는 터미널에서: `pythonw desktop_app.py`

---

## 삭제

1. `uninstall.bat` 실행 → 시작프로그램 해제
2. 이 폴더 삭제
