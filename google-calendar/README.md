# 선생님 캘린더 (데스크탑 위젯)

구글 캘린더 + 할일(TODO) + 공유 게시판을 Windows 바탕화면에 붙는 위젯으로 실행합니다.
`install.bat` 한 번이면 **설치 → 시작프로그램 자동 등록 → 실행**까지 끝납니다.

---

## 설치 (한 번만)

이 폴더 전체를 Windows PC에 복사한 뒤 **`install.bat`** 를 더블클릭하세요.

> **필요한 것: Python 3.12 권장** (3.11~3.13)
> 없으면 https://www.python.org/downloads/ 에서 설치하세요.
> 설치 화면에서 **"Add python.exe to PATH" 체크 필수!**
>
> ⚠️ **Python 3.14 같은 최신 버전은 피하세요.** 내장 브라우저(PyQt6-WebEngine)가
> 아직 호환되지 않아 위젯이 **흰 화면으로 멈춥니다.** 반드시 **3.12** 를 쓰세요.

설치 스크립트가 하는 일:
1. 이전에 설치된 버전(실행 중인 위젯·시작등록·옛 데이터)을 **자동으로 깨끗이 제거**
2. PyQt6 · PyQt6-WebEngine 패키지 설치
3. Windows **시작프로그램에 위젯 자동실행 등록** → 컴퓨터 켤 때 자동 실행
4. 위젯 즉시 실행

> 처음엔 수백 MB를 다운로드합니다. 인터넷 연결이 필요합니다.
> 검은 설치 창에 진행 상황이 한 단계씩 표시되고, 끝나면 멈춰서 결과를 보여줍니다.

### 설치가 안 될 때 (창이 떴다 바로 닫힐 때)
1. 폴더 주소창에 `cmd` 를 입력하고 Enter → 명령 창이 열립니다.
2. `install.bat` 을 입력하고 Enter → 이번엔 오류 메시지가 창에 남습니다.
3. 그 메시지(또는 같은 폴더의 `install.log`)를 그대로 캡처해 알려주세요.

## 구성

| 구분 | 설명 |
|------|------|
| **위젯** | 바탕화면에 뜨는 캘린더 카드. 버튼이 없는 순수 위젯입니다. |
| **설정 프로그램** | 작업표시줄 트레이의 **📅 아이콘을 클릭**하면 열립니다. |

### 위젯 조작
- **이동**: 위젯 위쪽 끝에 마우스를 올려 드래그
- **크기 조절**: 오른쪽 아래 모서리 드래그

### 설정 프로그램(트레이 📅 클릭)에서 할 수 있는 것
- 위젯 보이기 / 숨기기
- **투명도** 조절 (20 ~ 100% 슬라이더)
- **크기** 프리셋 (소 / 중 / 대 / 전체화면)
- **위치** 고정 (가운데 / 네 모서리)
- 항상 맨 위에 표시
- 벽지에 박기 (Windows, 보기 전용)
- 새로고침 / 완전히 종료

## ⚠️ 구글 로그인 설정 (최초 1회, 매우 중요)

구글은 앱 내장 브라우저에서의 로그인을 차단하므로, **로그인은 기본 브라우저(Chrome/Edge)에서** 진행됩니다.
이를 위해 구글 클라우드 콘솔에 콜백 주소를 등록해야 합니다.

1. https://console.cloud.google.com/apis/credentials 접속
2. 사용 중인 **OAuth 2.0 클라이언트(Web application)** 클릭
3. **승인된 리디렉션 URI(Authorized redirect URIs)** 에 아래를 모두 추가:
   ```
   http://localhost:8765/oauth2callback
   http://localhost:8766/oauth2callback
   http://localhost:8767/oauth2callback
   http://localhost:8768/oauth2callback
   http://localhost:8770/oauth2callback
   http://localhost:8800/oauth2callback
   ```
4. 저장 후 약 5분 기다렸다가 위젯에서 **"구글 로그인"** 클릭
5. 열린 브라우저에서 로그인 → "로그인 완료" 창을 닫으면 위젯에 자동 반영
   (캘린더 + 공유 게시판이 한 번에 로그인됩니다.)

> 할일(TODO) 목록은 로그인 없이도 바로 사용 가능합니다 (이 PC에만 저장).

## 파일 설명

| 파일 | 용도 |
|------|------|
| `index.html` | 캘린더 화면 본체 |
| `desktop_app.py` | 위젯 본체 (실행되는 프로그램) |
| `install.py` | 실제 설치 작업 (패키지 설치·시작등록·실행) — `install.bat` 이 호출 |
| `install.bat` | 설치 시작 (이것만 더블클릭) |
| `uninstall.bat` | 완전 제거 (위젯 종료·시작등록 해제·데이터 삭제) |

## 삭제

`uninstall.bat` 실행 → 폴더 삭제. 끝.
